# 飞书多维表格 · Word 模板排版打印插件

在飞书多维表格（Bitable）侧边栏中，用你自己排好版的 **Word 模板** 打印记录数据。选中一条记录，插件把字段值填入模板对应的占位符变量，浏览器内预览后直接打印，或下载填充好的 .docx。支持关联字段循环输出成表格、按字段值自动匹配模板、模板上传/复制/删除管理。

## 核心能力

- **自定义 Word 排版**：在 Word 里排好版式，用 `{字段名}` 占位符标记数据位置，保存为 .docx 即成模板。
- **模板自动匹配**：为每个数据表指定一个“匹配字段”，打开插件或切换记录时，用该字段的值自动选中同名模板（文件名去掉 .docx 等于字段值）。
- **模板搜索/筛选**：模板下拉支持搜索；模板管理页支持按名称筛选。
- **关联字段循环**：关联字段可展开为子表记录数组，用 `{#关联字段}…{/关联字段}` 循环片段把每条关联记录输出成表格的一行。
- **模板分页与求和**：在模板正文写一行 `@@PAGE` 指令，可设置循环明细的每页行数上限；产品超量时自动拆成多页同格式出货单，并对数字列自动求和、标注页码/总页数。详见下文“模板分页”。
- **模板正文编辑**：在“模板编辑”页直接修改模板的文字与占位符并写回 .docx，复制后的模板也能就地修改，无需重新上传 Word。详见下文“模板编辑”。
- **变量参考面板**：列出当前表所有可用变量（系统变量、字段变量、关联字段的子字段与循环片段），一键复制粘贴进 Word。
- **模板管理**：上传、复制（快速派生新模板）、删除、下载，方便实验员维护。
- **模板按数据表隔离**：每张数据表拥有独立的模板库（`templates/<tableId>/*.docx`），只看到、只能操作自己的模板，切换数据表时自动重新加载，互不干扰。不同表可以有同名模板。
- **模板存储在项目内**：所有模板以真实 .docx 文件保存并纳入 git，本地部署即可直接调用。

## 环境要求

- Node.js 16+（建议 18+）
- npm（已提供 lock 文件）

## 快速开始

```bash
npm install

# 启动开发服务（默认端口 5173）
npm run start
# 指定端口（macOS/Linux）
PORT=5199 npm run start
# 指定端口（Windows PowerShell）
$env:PORT=5199; npm run start
```

启动后本地地址为 `http://localhost:5173/`。作为飞书插件使用时，需要一个 HTTPS 地址（见下）。

## 作为飞书侧边栏插件使用

1. 启动本地 dev server（上一步）。
2. 用内网穿透工具（如 cloudflared、ngrok）把本地端口暴露为一个 HTTPS 地址，例如：
   ```bash
   cloudflared tunnel --url http://localhost:5199
   ```
3. 在飞书多维表格的插件配置里，把插件地址填为该 HTTPS 地址。
4. 在表格中从侧边栏打开插件，选中一条记录即可打印。

> **重要**：本插件依赖 dev server 提供的 `/api` 接口（模板增删、匹配配置）与 `/templates` 静态目录（模板取源）。因此 **生产使用方式 = 常驻运行 dev server + 内网穿透**，而不是把 `dist/` 当静态站点托管（那样没有后端 API）。

## 制作模板

1. 打开“变量参考”页，点“复制全部变量”，把变量清单粘进一个空白 Word 文档作为起点。
2. 在 Word 里排好版式，把 `{字段名}` 放到需要填数据的位置。
3. 关联字段用循环片段 `{#字段名}{序号} {子字段A} {子字段B}{/字段名}`，**开始标签 `{#…}` 与结束标签 `{/…}` 必须放在 Word 表格的同一行里**，每条关联记录会自动复制成一行。
4. 另存为 .docx，到“模板管理”上传。
5. 若文件名（去掉 .docx）等于某条记录匹配字段的值，选中该记录时会自动匹配到这个模板。

### 模板分页（出货单多页自动拆分与求和）

适用于“一张出货单有多行产品明细、超量需拆成多张同格式出货单”的场景。在模板正文**任意位置**放一行分页指令（渲染时引擎会自动隐藏这行，不打印）：

```
@@PAGE field=产品明细 size=5 sum=数量:合计数量,金额:合计金额 @@
```

- `field=`：作为循环明细的字段名（其值应为数组，如关联字段“产品明细”）。
- `size=`：每张出货单（每页）的行数上限，例如 `5`。
- `sum=`：需要自动求和的数字列，`列名:输出变量` 形式，多个用逗号分隔；上例会把“数量”列求和写入 `{合计数量}`、“金额”列求和写入 `{合计金额}`。
- 引擎行为：
  - 产品数 ≤ 每页上限 → 单页，仍注入合计与页码。
  - 产品数 > 每页上限 → 按上限切片，生成**多页同格式出货单**（合并为一个 .docx，打印即多张纸），每页注入对应的 `{合计数量}`、`{合计金额}`、`{页码}`、`{总页数}`。
  - 求和支持“12”“1,234.5”“￥100”“12个”等常见数字文本。
- 在“模板编辑”页可直接改写这行指令来调参（如把 size 改为 6）。

### 模板编辑

“模板编辑”页用于**不重新上传 Word** 就能改模板：

1. 选择要编辑的模板，插件提取其全部段落（含表格单元格）文本。
2. 直接在文本框里改文字或 `{占位符}`，只有“有改动的段落”会被写回 .docx。
3. 点“保存”即覆盖原模板。

> 注意：被改写的段落内部的多段格式会被合并为单一格式（保留首段字体/加粗等）。适合调整标签、占位符名称与分页指令；复杂版式微调仍建议用 Word 改完重新上传。

### 可用变量

- **系统变量**：`{打印日期}`、`{打印时间}`、`{数据表名称}`、`{记录ID}`
- **字段变量**：`{字段名}`（普通字段直接输出显示值）
- **关联字段**：
  - 循环：`{#关联字段名}…{序号}…{子字段名}…{/关联字段名}`（放进表格同一行）
  - 汇总文本：`{关联字段名_文本}`（不写循环时输出一段逗号分隔文本）
- **金额大写**：任意含「金额/总价/总金额/应收/应付/价税合计」的数值字段会自动生成 `{<字段名>大写}`（如 `{金额大写}`、`{合计金额大写}`），输出人民币大写（壹仟贰佰叁拾肆元伍角陆分）。

### Excel（xlsx）模板

- 支持上传 `.xlsx` 模板，占位符写法与 Word 完全一致：普通 `{字段名}`、明细循环 `{#字段}…{/字段}`（写在同一行内，按数据条数自动向下复制整行、合并单元格与边框随行下移）、`{合计数量}`/`{合计金额}` 自动求和。
- 预览为原格式保真渲染（合并单元格、边框、列宽、字体、对齐还原），可用缩放工具条。
- 打印/下载：打印走保真 HTML，下载得到填充后的 `.xlsx`。

### 打印方向与多联打印

- **打印方向**：打印页可选「跟随文档 / 竖向 / 横向」。当 Word 是竖版排版但内容是横向（如五联货单）导致被裁切时，选「横向」会自动旋转 90° 并切换横版纸张。
- **多联打印**：开启「多联(5联)」后一次连打 5 份（生产部/销售部/客户/财务部/开票），每份右上角标注联名。

### 说明与限制

- 取值与表格显示一致（日期、单选、多选等按界面格式输出）；复选框输出“是/否”。
- 附件字段只输出文件名，**不插入图片**。
- 字段名与系统变量重名时，以真实字段为准。
- 单个关联字段最多展开 50 条记录（超出会提示并截断）。
- 预览用于校对数据，复杂版式（文本框、浮动图片、页眉页脚）的完全保真以“下载 Word”后用 Word 打开为准。

## 长期部署（常驻服务 + 内网穿透）

生产使用方式 = 常驻运行 dev server（含 `/api` 与 `/templates`）+ 内网穿透暴露 HTTPS，供飞书插件访问。仓库提供了两套一键脚本：

| 系统 | 脚本 | 说明 |
|------|------|------|
| macOS / Linux | `deploy.sh` | pm2 守护 dev server + cloudflared 穿透；`start_at_login.sh` 供 LaunchAgent 登录自启 |
| Windows | `deploy.ps1` | 同上，PowerShell 实现；用计划任务实现登录自启 |

常用命令（两脚本参数一致）：

```bash
# macOS / Linux
./deploy.sh install     # 安装 npm 依赖 + pm2 + cloudflared
./deploy.sh start       # 启动 dev server + 穿透（pm2 守护）
./deploy.sh status      # 查看进程与穿透地址
./deploy.sh restart     # 重启
./deploy.sh stop        # 停止
./deploy.sh logs        # 实时日志（Ctrl+C 退出）
./deploy.sh startup     # 配置登录自启（按提示执行 sudo）
./deploy.sh tunnel      # 查看固定域名命名隧道配置步骤

# Windows（PowerShell，建议以管理员身份运行 startup）
.\deploy.ps1 install
.\deploy.ps1 start
.\deploy.ps1 status
.\deploy.ps1 startup
.\deploy.ps1 tunnel
```

- `start` 会打印一个 `https://xxx.trycloudflare.com` 临时地址，填进飞书插件配置即可；临时地址每次重启会变，需要固定域名见 `tunnel` 子命令（需自备 Cloudflare 域名）。
- `startup` 注册开机/登录自启，服务器重启后自动拉起服务。
- 模板与配置都在你本地（模板存 `templates/`），同事通过穿透地址在飞书里使用插件并提交/编辑模板。

## 常见问题

- **打印被拦截**：本插件用同源隐藏 iframe 打印，一般不会被弹窗拦截；若仍失败，改用“下载 Word”后在本地打印。
- **模板功能报“无法连接本地模板服务”**：确认 dev server 正在运行，且插件地址指向的就是这个 server。
- **自动匹配没生效**：到“模板管理 → 自动匹配设置”为当前表选一个匹配字段，并确认模板文件名与字段值一致。
